# v0.1.0-beta2 验证记录

记录日期：2026-10-21（北京时间）。

- 15 项前端测试通过：沿用 Beta1 的 9 项存储/备份测试，新增 6 项真实编辑器测试，覆盖中文选区加粗、撤销重做、常见 Markdown 语义往返、任务与表格重开、本地资产引用、危险链接/远程图片阻断、特殊语法回退和无编辑不重写。
- 3 项 Rust SQLite 测试通过，版本更新不改变数据库路径或格式。
- 浏览器交互验证：输入 `## ` 立即成为标题；中文连续输入、Ctrl+B、Ctrl+Z / Ctrl+Shift+Z、粘贴任务/引用/表格、任务勾选、源码切换、自动保存后重开均正常。
- 含脚注的源码保持原文并提示，拒绝进入无法等价转换的实时编辑模式；恢复为支持的语法后可正常切回。
- PNG 的 alpha 范围为 0–255，角落透明；ICO 的 16/24/32/48/64/128/256 像素帧均保留透明通道。512 像素图标可见边界为 (67,66)–(445,440)，比 Beta1 留白更多。

本版尚未执行用户现有安装的覆盖安装或 Beta1 → Beta2 完整自动升级，不据此宣称已完成跨版本安装验收。浏览器验证采用独立 IndexedDB，原生 SQLite 由 Rust 测试验证。

# v0.1.0-beta1 验证记录

记录日期：2026-10-21（北京时间）。

前端测试涵盖：数据引用与 ID 约束、备份往返、修改后的备份拒绝导入、恶意路径拒绝解压、同名文档安全导出、重开持久化、旧版本冲突拒绝覆盖并保留草稿、三语关键资源和 SHA-256。

已在原生 WebView2 应用中创建入门文档，确认 SQLite revision=2、正文已落盘，正常关闭后重开文档仍然存在。
浏览器预览实测 DOCX 正文与内嵌 PNG 提取、图片预览、PDF 正文提取、包含图片的完整备份导出与恢复；恢复后文档从 3 篇增加为 6 篇，原文档保留。
DOCX 与 PDF 合成样本的导入前后 SHA-256 一致；简体、繁体和英文设置均已在界面中切换验证。

浏览器预览验证与原生构建验证应分别记录；浏览器数据独立保存于 IndexedDB，不据此宣称桌面 SQLite 已经端到端验收。
v0.1.0-beta1 是首个预发布版本；首次发布只能验证更新检查与安装包签名，真实的跨版本升级需要在后续版本发布时补充回归验证。
