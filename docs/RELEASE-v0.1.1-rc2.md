# Orvia v0.1.1-rc2

优化编辑工具栏磨砂玻璃悬浮效果，调整搜索框圆角、边框与背景对比。

- 编辑工具栏承载层改为透明，不再显示横贯正文的白色底层；格式、查找、撤销/重做胶囊各自使用半透明底色、背景模糊、细边框与轻阴影，滚动时悬浮于正文上方。
- 保留原有分组、间距和操作；工具栏空白间隙不阻挡正文的鼠标操作。
- “全部文档”主搜索框采用两端全圆的胶囊轮廓，轻微加深边框。
- 文档列表小搜索框新增独立底色与边框，同样采用胶囊圆角，避免与页面背景混在一起；输入焦点状态更清晰。
- 同步适配浅色、深色、窄窗口与高对比模式；不支持背景模糊时只对胶囊本身使用可读的底色降级。

既有编辑、搜索与数据保护行为保持不变。Windows Authenticode 按既有要求不启用，更新包继续使用现有 Ed25519 签名。
