# 本地数据与备份安全

普通知识库仍采用 SQLite 和独立图片文件，不因新增加密功能而自动加密。加密知识库是独立空间；选择复制时，普通空间、旧备份、外部导入源文件和磁盘残留不会被安全擦除。

## 加密空间

- Web Crypto PBKDF2-HMAC-SHA256，600,000 次，随机 16 字节盐，派生不可导出的 AES-256-GCM 密钥。
- 每次提交、草稿检查点和备份使用独立随机 12 字节 IV，128 位认证标签，认证附加数据绑定格式、版本及 KDF 参数。
- 正文、图片字节、历史、回收站、设置、阅读位置和恢复草稿存放在加密载荷内；明文不写入普通空间的 SQLite、资源目录或阅读位置 localStorage。
- 解锁页语言及上次使用的空间保留为非内容偏好；这两项提示不包含笔记或密码。
- 锁定前保存；主保存失败时必须有已保存的加密恢复草稿，才允许锁定。默认空闲 5 分钟锁定，可设为 1/5/15/30 分钟。密码无法重置找回。
- 更改密码不会更改历史备份的密码。恢复备份需输入创建备份时的密码；合并为新笔记，保留当前空间及设置。
- 加密保护静态磁盘内容，不保证已解锁内存、系统交换文件、恶意软件控制的会话、手动导出的明文 Markdown/PDF/HTML 或密码强度。JavaScript 字符串与系统内存不提供可靠安全擦除保证。
- 密文载荷最大 80 MiB，封装文件最大 128 MiB。超过限制时拒绝提交并保留已有文件，不以删减内容解决。

## 备份与恢复

手动普通备份包含知识库、历史版本、设置、图片及回收站；恢复前显示清单，默认合并为新笔记，保留当前设置，可明确选择恢复设置。v1 备份继续可读。v2 额外对历史清单做 SHA-256 完整性校验；普通 ZIP 的哈希用于损坏检查，不等于来源认证或加密。

自动备份默认关闭。选择目录时由原生对话框授权，并创建带随机标记的独立 `Orvia Backups …` 子目录。仅应用打开、空间已解锁时运行，15 分钟/1 小时/每日可选；普通空间可选择历史与回收站，加密空间始终生成完整加密备份。各空间保留 3–50 份，只删除该目录中符合自身命名规则的自动备份。不会清理其他文件或未授权目录。

损坏或中断的普通恢复文件移至隔离文件保留；损坏的加密草稿保持密文隔离。可以从存储管理导出诊断原件。普通隔离文件可能含私密笔记，勿随意分享。

## 文件与更新边界

PDF 输出需经原生保存对话框批准，返回绑定当前窗口、5 分钟有效、单次使用的令牌；前端不能传任意目标路径。资源文件通过哈希名读写，图片导入限制文件大小、尺寸、像素并检查浏览器解码；ZIP 同时检查条目声明和实际展开总大小，拒绝路径穿越、重复条目。导入任务可取消并有超时；有界同步解析执行中的步骤不支持硬抢占。

资源清理先预览再确认，保留正文、回收站、历史、恢复草稿和隔离草稿引用；原生删除前再次检查引用。无法扫描恢复文件时拒绝清理。

稳定更新通道只接收正式发布，预览通道包含测试版；切换预览需确认。更新通过现有 Tauri Ed25519 密钥验签，校验失败不安装。用户已取消 Windows Authenticode 代码签名，本版本安装器不作该项签名声明。
