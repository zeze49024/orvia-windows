# v0.1.0-rc1 验证记录

## 功能与交互
- 所有文档、最近打开、星标及各知识库列表统一支持卡片右键删除和多选。
- 多选胶囊提供移动、独立置顶/取消置顶、移入回收站、导出和分享；切换列表或筛选重置选择，筛选输入保留焦点。
- 置顶优先于当前排序；置顶与收藏独立，旧记录默认未置顶。批量修改使用同一次 SQLite 增量事务，不更改数据库表结构。
- Markdown 导出可选独立文件或平铺 ZIP，文件重名自动编号。原生写入使用 createNew，避免覆盖；取消不写文件，部分失败报告成功数量。
- 分享生成包含笔记和本地图片的离线 HTML；原始 HTML、脚本和远程图片不执行或加载，不上传笔记内容。
- 设置改为独立页面，含返回入口、搜索及六个分类；兼容三语与浅深主题，返回保留正文和撤销历史。

## 本地验证
- 41 项单元测试通过：旧字段兼容、批量状态修改、图片与 Markdown 往返、ZIP 内容、HTML 转义与离线限制、原生文件写入适配器的重名/取消/部分失败行为。
- 5 项 Rust/SQLite 测试通过，包括批量事务原子性、失败回滚、置顶与收藏重开保留。
- 13 条浏览器端到端流程通过：现有写作兼容性、批量移动/置顶/删除/恢复、独立 .md 与 ZIP/HTML 下载、设置搜索与返回、筛选输入焦点、三语和 900px 浅深主题。
- TypeScript、生产构建和安装包构建；签名与真实 Windows 安装升级结果在发布验收后补充。
- 浏览器预览使用独立 IndexedDB。原生测试和 CI 使用一次性测试数据，不接触用户正式知识库。
- 文件写入适配器的单元测试模拟系统目录选择；未据此声称已人工验收所有 Windows 文件对话框。
