# v0.1.1-beta1 验证记录

## 功能与兼容性

- 实时编辑与源码的文字查找替换；实时模式跨粗体等行内标记查找，保持无关格式。全部替换为一个撤销步骤；源码替换不解析或重写不支持的 Markdown。
- 图片粘贴与拖入复用本地内容哈希资源存储与真实 MIME 校验；仅接受 PNG/JPEG/WebP/GIF，单图不超过 20 MB，批次不超过 128 MB。
- Tauri Windows 关闭原生拖放拦截，让 WebView2 的 HTML 文件拖放进入同一受校验的导入路径。
- 图片宽度使用标准 Markdown 图片 title 的 orvia-width 元数据，第三方编辑器可忽略；保留原始标题与替代文字。缩放不修改图片原始字节，不插入原始 HTML。
- 编辑模式、实时及源码选区、外部与源码内部滚动偏好在本地 WebView2 存储中按笔记 ID 保存，最多保留 200 篇；不修改文档更新时间或加入正文历史。
- 位置偏好不属于知识库备份，清除应用浏览器存储后不会恢复；正文和图片仍由原有 SQLite/本地资源保存。
- 新界面文字覆盖简体中文、繁体中文和英文。

- 实时编辑的大批量替换上限为 5000 项，超过时提示切换源码模式；源码替换按片段线性拼接，避免逐项重复复制长文。高亮最多绘制前 2000 项及当前项，匹配计数仍显示全部。

## 已通过的本地检查

- 54 项单元测试、5 项 Rust/SQLite 测试、23 条浏览器端到端流程全部通过，TypeScript 与生产前端构建通过。
- 新增流程实际验证跨行内格式查找、文字匹配与大小写、单项和批量替换及撤销、不支持的 Markdown 源码保留。
- 文件事件中的图片载荷实际进入本地资产存储；预览与替代文字、显示宽度、重载保存、伪造图片拒绝、单文件 Markdown 下载内容均有断言。
- 光标选区与滚动位置覆盖设置返回、笔记关闭重开、页面重启；切换源码后立即重启也保留模式。
- 图片粘贴与拖放验收使用文件载荷事件注入，不替代所有操作系统剪贴板和鼠标设备的人工兼容性验证。
