# v0.1.1 正式版验收

- 使用用户提供的五条原文日志，见 RELEASE-v0.1.1.md；README 主标题同步为 v0.1.1 正式版。
- TypeScript、75 项单元测试、27 项原生测试及完整 49 项界面回归均通过。
- 新入口位于星标文档正下方，复用轻提醒，2.5 秒后自动消失。重复点击刷新同一条提示；主页及编辑中点击均不导航、不清空正文、不打开模态框。三语资源齐全，简体提示逐字匹配“⚠️新功能开发中，敬请期待！”。
- 单篇 Markdown/PDF 导出在生成快照、选择目标之前等待最新正文保存完成；批量和完整备份继续使用既有保存边界。正常关闭在导出作业进行中被拦截，非导出状态关闭前仍等待保存。
- 正式版发布工具为 stable 与 preview 两种目标均提供同一签名安装器，并准备 stable/preview/latest 三份 feed；仅在公开产物和安装验收通过后推进。发布工具测试验证两个通道不误选 beta/rc 安装器。
- 原生验收新增：触发实际 PDF 导出，暂挂文件目标选择；确认最新正文已进 SQLite 后点击原生关闭按钮，验证关闭被拦截、取消导出并重载后正文仍存在。只暂停测试环境文件目标 IPC，不绕过真实窗口事件与持久化。

安装包、rc2 和 v0.1.0 升级、实际签名更新的最终证据在完成后补充。测试不使用真实 API Key 或付费推理。按既有要求不启用 Windows Authenticode，沿用 Ed25519 更新签名。
