Orvia v0.1.0 正式版汇总 beta1–beta8 与 rc1–rc3 的更新，完成应用初版构建。

- 编辑与写作：新增所见即所得 Markdown 编辑体验，支持 H1–H6 标题选择及文档大纲；优化文档名称显示、编辑操作、写作稳定性与 Markdown 文件兼容性，并完善文件往返回归验证。
- 文档与知识库：完善图文导入导出，支持单篇 Markdown 导出，以及批量独立 .md 或 ZIP 导出；新增笔记右键菜单、单篇快捷移动、批量管理、置顶和分享；删除与移动操作增加二次确认。
- 保存与恢复：新增增量保存和历史恢复，完善本地文档管理与数据持久化验证。
- 界面与主题：修复 Windows 图标白色背景，优化应用图标、首页与整体可读性；调整功能图标配色、收藏状态和编辑工具栏胶囊布局；新增浅色、深色主题及主题扩展接口，并将设置改为独立页面。
- 版本更新：支持自动检测 GitHub 新版本，在首页显示更新徽章并提供快捷下载更新；设置中可关闭自动检测。
- 工程质量：重构代码，加强安装升级、编辑、文件兼容与回归验证。
