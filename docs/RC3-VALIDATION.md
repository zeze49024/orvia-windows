# v0.1.0-rc3 验证记录

## 功能
- 所有文档、最近打开、星标及各知识库列表的笔记卡片右键菜单新增“移动到”，直接选择目标知识库并二次确认，无需先进入多选。
- 右键单篇目标与多选集合独立；确认仅移动右键笔记，取消不修改笔记。移动保留正文、标签、收藏和置顶。
- 批量胶囊的“导出 Markdown”文案改为“导出”，继续提供独立 .md 或 ZIP，两种导出内容不变；三语资源同步。

## 验证范围
- rc3 浏览器专项覆盖四种列表入口、取消与确认、移动后重开保留、正文及元数据完整、多选与单篇目标隔离；现有导出端到端继续校验 .md / ZIP 文件内容。
- 单元测试、SQLite 原生回归、完整界面回归和生产安装包构建的实际结果在完成后记录。
- Windows 隔离环境使用最终 rc3 安装包从 rc2 升级；新增真实右键单篇移动 → 二次确认 → SQLite 持久化检查，不触碰用户正式知识库。

## 已通过的本地检查
- 47 项单元测试、5 项 Rust/SQLite 测试、19 条界面端到端流程通过。
- 右键移动覆盖全部文档、最近打开、星标、知识库列表；取消不移动，确认后重开保留目的地、正文、标签、收藏和置顶。
- 已选 B 时右键移动 A，只移动 A，B 的选择和知识库不变；批量移动、删除确认、自动检测和原有写作/导入导出回归通过。
- 导出按钮改为三语通用文案；既有流程实际下载并解包 ZIP，检查独立 .md 和图片内容。
