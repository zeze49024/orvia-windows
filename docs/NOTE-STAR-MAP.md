# 笔记星图

v0.1.2-beta1 起，左侧“星标文档”下的预留入口替换为“笔记星图”。读取当前本地空间，不连接 AI 服务，不新增网络请求，不修改笔记或数据库结构。加密知识库继续遵循既有空间解锁和自动锁定机制，不混合普通空间数据。

## 浏览与操作

- 力导向、环形、径向与网格四种布局；布局坐标只在当前页面生效。
- 拖动空白画布平移，滚轮或底部按钮缩放；拖动节点调整位置，“适应画布”恢复布局位置并居中。
- 单击查看详情、强调相邻关系；双击笔记打开编辑器，双击知识库打开文档列表。
- Tab 聚焦节点，Enter 打开，空格查看详情；Esc 关闭详情并退出展开视图。
- 点击图例筛选分类，输入标题/标签关键词，或限定某个知识库。“重置星图”恢复全部筛选及力导向布局。

## 连线与分类

虚线表示笔记归属，实线表示明确的本地笔记链接。支持双方同一空间的 [[标题]]、[[知识库/标题]]、Markdown 本地 .md 链接、Markdown 引用式链接和 orvia://note/笔记ID；互相链接合并为一条无向连线。标题重名时不猜测，使用知识库限定名或笔记 ID。外部 URL、图片、代码及回收站笔记不生成关联，正文中的普通词语也不会被猜测为链接。星图支持解析这些文本，编辑器现有链接行为保持不变。

节点分类优先级为：置顶 > 日记 > 热门 > 普通。日记由日记/日記/diary/journal 标签或日期开头的标题识别；热门指当前显示范围内至少连接三篇不同笔记，不按点击量计算。金色小圆点表示收藏。

## 性能与边界

每个视图显示最多 500 篇未删除笔记，置顶优先、其次最近更新，可按知识库切换显示范围。解析每篇前 100,000 字符；超出范围的引用不会显示。底部会提示笔记总数与显示限制，不能将部分视图理解为完整全库关联统计。

Markdown 解析在打包的本地 Web Worker 中执行，不上传内容、不运行 HTML/脚本、不访问链接目标；退出页面终止线程。工作线程失败时显示重试入口，不影响原文。力导向使用空间分桶与固定迭代次数；SVG 节点文字保持可读字号，明暗主题与三语资源沿用应用设置。
