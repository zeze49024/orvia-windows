# Orvia v0.1.1-beta3

加强文件权限与导入防护，完善备份恢复和更新通道，新增加密知识库、存储管理、高级搜索、笔记模板及快捷键与无障碍支持。

- PDF 输出使用原生保存对话框批准的一次性令牌，拒绝任意输出路径和令牌重复使用。
- 损坏恢复文件隔离保留，可导出诊断原件；资源清理保留笔记、回收站、历史和恢复草稿使用的图片。
- 新增稳定/预览更新通道；稳定通道默认开启，预览通道需明确选择。更新包继续验签。
- 支持自动备份目录授权、间隔与保留份数；普通完整备份包含历史、设置和回收站，恢复前可预览并选择是否恢复设置。
- 加强图片像素和解码限制、ZIP 实际展开大小及路径检查，增加导入超时和取消保护。
- 新增独立加密知识库，覆盖笔记、图片、历史、草稿、回收站及加密备份，支持手动/空闲锁定、密码更改和加密备份恢复。
- 新增按内容范围、知识库、收藏与日期组合的高级搜索，以及摘要和正文命中定位。
- 新增内置/自定义笔记模板、快捷键修改与冲突校验，改善键盘导航、状态播报及减少动画支持。

加密知识库不会自动加密或删除普通知识库与旧备份，密码无法找回。自动备份仅在应用打开且空间已解锁时执行。具体边界见 [本地数据与备份安全](https://github.com/zeze49024/orvia-windows/blob/main/docs/SECURITY-AND-BACKUPS.md)。

Windows Authenticode 代码签名已按开发者要求取消；本版本不包含该项签名，保留现有 Tauri 更新包签名。
