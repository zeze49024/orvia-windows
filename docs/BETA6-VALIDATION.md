# v0.1.0-beta6 验收记录

更新日志：完善图文导入导出与文档管理，新增增量保存和历史恢复，优化编辑与首页体验，重构代码并加强安装升级验证

## 对应七项问题

1. Markdown 导出的内嵌图片在导入时重新存入校验过的本地资源；只处理实际图片节点和图片引用，代码示例保留原文。PNG/JPEG/WebP/GIF 有类型、单图和总量限制，不发起远程图片请求。
2. 原生 SQLite 和浏览器预览均按变化记录保存；主题变更不提交文档正文。事务保持版本冲突检查。历史记录每分钟一个自动检查点，每篇最多 20 个、20 MB；恢复前强制保存当前版本，支持再次恢复。历史保存在本机，完整备份包含当前文档与资源，不包含历史列表。永久删除同时删除该文档历史。
3. 新增独立 Windows CI 安装升级验收：实际运行 beta5 安装包、启动 WebView2 写入测试文档、覆盖安装 beta6，再验证中文、标签、星标、增量保存、历史和界面重载。只在一次性 runner 上执行。签名包在本机生成，CI 候选安装包为同源码无更新签名构建；正式签名与资产校验另行验证。
4. 编辑器“文档选项”恢复移动知识库、标签和历史管理，右侧仅保留大纲。
5. 压缩文档信息，固定格式栏；大纲按滚动/光标高亮，源码用相同排版镜像测量换行位置；图片插入光标处；自身输入不再重复解析 Markdown 语义等价性。
6. 首页搜索与继续编辑优先，统计收为一行；备份入口改用归档图标。
7. 入口、应用协调、编辑区、首页、设置、文档选项、异步任务管理、增量差异及原生持久化按职责分离，新增界面统一尺寸变量并复用现有主题色。

## 已执行的本机检查

- 30 项前端/资源测试通过，其中新增图片字节级往返、MIME 拒绝、1,000 篇文档差异提交和历史重新打开恢复测试。
- 4 项原生 SQLite 测试通过；1,000 篇中一篇编辑只写入文档、历史、版本号共 3 行，失败事务不更改正文和历史。
- 3 条浏览器端到端流程通过：保存/恢复/主题持久化；H1–H6/撤销重做/源码大纲与固定工具栏；真实文件选择导入图片并导出后重新导入。

安装升级 CI、正式构建与签名发布结果在发布前补充。
