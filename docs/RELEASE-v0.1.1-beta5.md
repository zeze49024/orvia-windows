# Orvia v0.1.1-beta5

重构 AI 侧边聊天面板，新增选中文字快捷操作、连续对话与本地会话管理，优化修改审阅及上下文授权体验。

- 采用已确认 A 方案：编辑页右侧聊天面板，支持展开/收起、固定输入区和独立消息滚动。保留原有 AI 按钮，基于 shadcn/ui 统一卡片、标签、输入框、提示和确认界面。
- 选中文字后右键新增“询问 AI、润色、扩写、总结、翻译”；支持源码和可视编辑模式，选区以可展开、移除的引用展示。
- 支持连续追问与本地会话的新建、切换、重命名和确认删除；对话按笔记及本地空间隔离，加密知识库的会话随空间加密，锁定后清除解密状态。
- 每次发送前可审阅选区/当前笔记/不附带笔记、指令及携带的会话上下文；随后仍需原生授权。只发送当前会话中最近能容纳的最多 20 条历史，明确展示裁剪情况，默认不会发送其他会话。
- AI 回复支持安全 Markdown 排版，不执行 HTML、远程图片、外链或代码。每条回复提供复制、光标插入与继续追问；替换选区、替换整篇笔记、插入内容分别审阅确认。
- 应用修改前校验当前原文、空间与选区位置；保留修改前历史，拒绝过期建议与未授权图片引用。导入备份后的旧建议只供查看，需重新生成后才能直接替换。
- 本地会话上限 40 段，每段 80 条消息，总计 4 MiB；到达上限提示用户管理旧会话，不静默清理。永久删除笔记时清理关联对话，备份恢复会重建关联。
- 保留用户自带 DeepSeek/OpenAI Key、Windows 凭据管理器、固定官方接口、输入/输出/轮次/时间上限及停止控制，处理停止早于原生任务登记的竞态，不自动重试。

AI 仍默认关闭。使用自己的 Key 和支持工具调用的模型，API 费用由服务商收取。本次没有真实用户 Key，协议和界面通过模拟请求验证，未进行付费推理。Windows Authenticode 代码签名保持取消；保留既有 Tauri Ed25519 更新包签名。
