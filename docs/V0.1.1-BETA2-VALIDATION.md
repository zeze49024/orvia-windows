# v0.1.1-beta2 验证记录

## 保存与恢复

- 保存中显示进度图标，失败显示错误图标与重试入口；失败内容继续留在内存，恢复成功前不清除错误提示。导出备份/Markdown 仍可取出当前内容。
- 主数据库之外记录草稿检查点：Windows 为本地 writing-recovery.json，120 ms 合并写入、临时文件写完并同步后原子替换；浏览器预览为独立 IndexedDB 数据库。
- 数据库写入前等待当前草稿检查点，数据库写成功后更新草稿；已提交相同内容不会在下次启动误报。
- 恢复对话框展示草稿预览，选择恢复时创建副本，不覆盖原笔记；稍后处理保留提示，丢弃需要确认。草稿保护失败会明确提示，不承诺绝对零丢失。
- 草稿检查点不属于备份文件；保护文件最大 64 MiB，超限或不可写时提示并继续保留窗口内容。

## PDF 导出

- 编辑页独立“导出 PDF”入口。Windows 选择文件后，由 WebView2 PrintToPdf 本地生成 A4 PDF，完成后才替换目标文件，失败不覆盖原文件。
- 导出内容使用独立浅色排版，保留中文文本、标题、列表、表格、代码及已验证的本地图片；正文可选择和提取。界面侧栏、工具栏不进入 PDF。
- 等待字体与图片解码，不访问远程图片，不执行原始 HTML。图片宽度遵循已有 Markdown title 元数据。
- 浏览器预览通过打印对话框另存 PDF，关闭对话框不会谎报文件已保存。
- 使用 PDF 技能做结构和页面渲染检查；此处生成的文件是验收样本，非用户知识库文档。
