# v0.1.0-rc3 验证记录

## 功能
- 所有文档、最近打开、星标及各知识库列表的笔记卡片右键菜单新增“移动到”，直接选择目标知识库并二次确认，无需先进入多选。
- 右键单篇目标与多选集合独立；确认仅移动右键笔记，取消不修改笔记。移动保留正文、标签、收藏和置顶。
