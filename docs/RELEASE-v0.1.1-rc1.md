# Orvia v0.1.1-rc1

优化设置各页面布局，统一分组、间距与表单样式，提升界面紧凑度和可读性。

- 统一全部九个设置分类的导航、页面标题、说明、分组卡片、行间距和表单控件，减少多余留白，保持清晰的阅读层次。
- 常规与外观优先显示；AI、模板快捷键、安全、导入导出、存储备份、版本更新和关于各自保持独立页面。
- AI 设置分为服务配置、密钥授权和调用控制，服务商与模型并排、调用限制集中排列；保留一次授权和原有保存操作。
- 存储备份分为本地数据、自动备份、资源管理；备份参数并排，相关操作就近排列。
- 模板与快捷键分组展示，模板选择与名称并排，快捷键名称与输入框统一对齐；安全页面与通用表单保持一致。
- 优化浅色、深色和窄窗口排版；分组、按钮和长路径随可用宽度换行，保留三种语言及键盘焦点提示。
- 应用版本显示统一读取发布配置，确保设置和安装包版本一致。

既有数据格式、加密方式、权限和操作确认保持不变。不使用真实用户 API Key 或付费推理验证界面。Windows Authenticode 按既有要求不启用，安装更新包继续使用已有 Ed25519 签名。
