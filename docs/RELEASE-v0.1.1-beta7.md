# Orvia v0.1.1-beta7

打磨 AI 聊天界面与交互，优化阅读定位、输入反馈、会话管理及上下文状态展示。

- 保留右侧 AI 面板，统一 shadcn/ui 控件、留白、字体层次和焦点反馈；优化浅色、深色与窄窗口布局。
- 阅读旧回复时，新回复不再强制滚到底部；提供“回到最新回复”按钮。
- 等待回复时可以起草下一条消息，不自动发送；补充快捷键和输入字数提示，兼容中文输入法确认操作。
- 会话记录支持按标题搜索，显示更新时间和消息数量。面板内切换会话保留各自未发送的草稿；草稿不写入长期存储，关闭面板后清除。
- 上下文栏准确区分当前笔记、选中文字和仅本会话，可直接点击调整；发送中的范围固定，避免误解。
- 回复代码块支持单独复制，复制后就地显示反馈；优化标题、表格、引用和修改建议的阅读层次。
- 停止生成使用中性状态提示，保留已有消息和下一条草稿；失败后可重新编辑原提问，不自动重试或重复扣费。
- 保留配置 Key 时一次授权、主动发送、调用控制和笔记修改前的差异审阅与确认。

Windows Authenticode 代码签名按用户要求保持取消；安装更新包继续使用既有 Ed25519 签名。模型交互使用模拟传输和本机协议测试，无真实用户 Key 或付费推理。
