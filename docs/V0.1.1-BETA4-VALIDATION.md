## 范围

当前笔记问答/总结/写作建议，DeepSeek/OpenAI 自带 Key，Windows 凭据存储、原生发送授权、修改差异与确认、并发冲突、历史恢复、调用上限及取消。默认关闭，跨知识库与外部智能体接入不在首版范围。

## 当前结果

- 前端 68 项单元测试通过，包含旧版本功能、AI 冲突拒绝、历史保留、图片引用保护和错误脱敏。
- 原生 21 项测试通过，包含凭据管理器独立命名空间真实读写/删除、固定服务地址、两家请求格式、只读/编辑工具白名单、错误/截断/超大响应拒绝、轮数和中止后无后续调用。模型请求通过本机 HTTP 测试服务，无真实 Key，无付费推理。
- 新增 2 项 AI 界面回归通过：授权勾选、Key 输入清空与不进入工作区、纯文本输出、差异、取消/确认、持久历史、迟到响应和图片保护。
- 全量界面 33 项回归通过。最终安装器、公开文件校验及真实升级结果完成后补录；不把模拟请求等同于真实厂商调用。

- 本地独立验证目录的正式构建已通过：AI 默认关闭、虚构 Key 保存后清空输入、Key 不进入工作区、原生授权拒绝后返回取消、Key 删除与停用成功。未发送真实推理请求。
- `npm run package` 成功，7 个 PE 图标与显式窗口图标检查通过；更新包签名、公钥匹配和可信注释校验通过，篡改安装器被拒绝。
