# AI 笔记助手的权限与实现边界

AI 是可选的 Windows 本地编排功能，不需要部署 Orvia 服务器或本地大模型。普通笔记管理仍可离线使用。

## 配置与请求

默认关闭。全局非敏感配置保存在应用数据目录的 `ai-config.json`；不随知识库、恢复包或加密备份迁移。Key 单独进入当前 Windows 用户的 Credential Manager，按应用数据目录和服务商分隔命名空间；验证目录使用不同目标，不触碰正式用户凭据。UI 不读取已保存 Key，保存后清空输入框。

首版仅支持以下固定 HTTPS 地址，拒绝重定向，没有自定义地址、第三方中转或内置开发者 Key：

- DeepSeek：`https://api.deepseek.com/chat/completions`
- OpenAI：`https://api.openai.com/v1/chat/completions`

连接测试仅请求对应 `/models`。模型列表不保证每个模型支持文本和工具调用；请选择支持 Chat Completions function calling 的模型，Responses 专用模型不在本版适配范围。OpenAI 不自动替用户选择模型；DeepSeek 提供可编辑的 `deepseek-flash` 初始值。

协议依据：[OpenAI Function Calling](https://developers.openai.com/api/docs/guides/function-calling)、[DeepSeek Tool Calls](https://api-docs.deepseek.com/guides/tool_calls/)。请求格式差异由原生适配器处理，工具参数仍由本机校验。

## 授权和数据

用户先在发送审阅框确认本次范围、指令和会话上下文，再经过原生授权对话框确认服务商、模型、笔记、历史条数和加密空间状态。范围分为选中的 Markdown 片段、当前笔记、不附带新的笔记文字；移除片段不会自动扩大为整篇。仅附带当前会话中最近、符合输入预算的最多 20 条 user/assistant 消息，审阅框可展开查看并提示裁剪。附件字节、其他会话、其他笔记、数据库、磁盘文件、凭据不作为工具提供。图片引用是 Markdown 文字的一部分，图片文件本身不上传。

加密知识库的云端 AI 输入是解密文字，不再由本机磁盘加密保护。启用 AI 不等于启用云同步，但授权内容将由服务商处理并遵守其数据政策。界面回复支持安全 Markdown，不执行 HTML、SQL、命令或网络访问要求；图片与外链不发起网络加载。

## 工具与保存

- `read_current_note`：仅在笔记/选区范围提供，返回已授权正文或片段，参数必须为空，不能切换 ID。不附带笔记时不提供工具。
- `propose_note_edit`：仅允许建议修改、已完成前一轮读取后可用；笔记范围返回完整标题/正文，选区范围仅返回替换片段。返回建议，不执行写入。选区替换与插入由原编辑器按保存的位置生成待审阅 Markdown，再走历史保存路径。源码直接映射字符区间，可视模式通过 ProseMirror 文档切片处理；不支持无损可视解析时提示切换源码。

问答模式不提供修改工具。未知工具、额外参数、截断响应或非法格式导致拒绝；本机不以模型自述替代授权。

应用建议前检查文档 ID、原文、标题、是否删除、是否锁定和空间状态；用户确认后再次检查，再走现有增量保存与强制历史快照流程。图片 asset 引用集合必须保持不变，避免引入未授权资源或丢失图片。失败保存仍受现有草稿恢复与重试保护。

## 限制与取消

输入上限可选 16,000/32,000/64,000 字符；每轮输出上限 1,024–8,192 Token；最多 2–4 轮。响应最多 2 MiB，建议正文最多 120,000 Unicode 字符，整次任务最长 180 秒（含授权等待）。单个 HTTP 请求最多 90 秒；禁用自动重试及重定向。实际用量按服务商返回值显示，账单以服务商为准。

聊天保存在当前工作区的设置载荷中，由现有 SQLite/IndexedDB 增量保存事务持久化；加密空间直接进入加密 workspace，不写明文聊天缓存。每个空间最多 40 段会话，每段 80 条消息，总计 4 MiB；按笔记隔离列表。关闭、换笔记、进入设置或锁定会取消当前任务并丢弃迟到的结果，已保存历史保留。永久删除笔记清理关联对话。备份恢复会重建会话与笔记 ID 关联；旧建议的原文指纹和位置不再有效，只供查看。停止会终止本机继续读取响应和后续工具轮次，无法保证服务商停止已收到的推理，也无法撤回数据或费用。

## 验证方法

协议与越权防护通过本机 HTTP 测试服务验证，测试地址只传入 Rust 私有测试入口，生产命令的服务地址固定。界面回归模拟 AI 传输模块，不引入生产测试开关或绕过授权。Windows 凭据读写使用临时数据目录命名空间和非真实 Key，完成后删除。

没有用户 Key 时不向真实厂商发送推理请求、不使用用户额度。实际模型可用性、账户地区、权限、额度和厂商网络连接需由用户在配置自己的 Key 后验证。
