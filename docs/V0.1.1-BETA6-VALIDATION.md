# v0.1.1-beta6 验证记录

- 已确认版本与日志见 RELEASE-v0.1.1-beta6.md。
- TypeScript 检查通过；75 项单元测试和 26 项原生测试通过。新增动画默认迁移、三档时长及减少动态效果滚动策略；授权记录绑定 Key/服务商/目录/策略、无明文 Key、撤销、不同目录复制无效及非法路径拒绝。
- 完整界面回归 38 项通过。查找胶囊位置/尺寸/间距及功能、三档动画保存和系统减少动态效果、授权后直接发送且不出现消息确认框、撤销后禁发/重新授权恢复、重复快速发送仅调用一次，以及既有编辑、会话、加密、导入导出、备份、升级发现回归。
- 页面过渡使用既有视图的 Web Animations，不通过 key 重建编辑器。输入、撤销、选区、跨页面位置及 IME 现有回归通过。

安装包、Windows 原生设置授权及跨版本升级证据见下文。模型请求采用本机模拟服务，无真实 Key 或付费推理。按用户要求不做 Windows Authenticode，保留更新包签名。

本地正式构建在独立 marker-gated 目录验证通过：原生设置授权拒绝/接受、授权跨重启保存、撤销后原生 AI_AUTHORIZATION_REQUIRED 拒绝发送、Key 输入清空/删除、聊天记录和急速动画偏好恢复。使用虚构 Key，并通过预先取消阻止授权路径发起 HTTP，没有真实推理。`npm run package` 成功，7 项 PE 图标及显式窗口图标检查通过。
