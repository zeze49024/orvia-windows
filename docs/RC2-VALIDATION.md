# v0.1.0-rc2 验证记录

## 已确认的行为
- 右键、批量及编辑页删除，批量及文档选项移动，删除空知识库均二次确认；取消与 Escape 不修改笔记。确认框显示名称/数量及移动目标，默认焦点为取消。永久删除保留不可恢复提示和笔记名称。
- 启动后 10 秒及运行期间每 6 小时检测更新，忙碌时延后重试。自动检测默认开启，设置关闭后重启保留；手动检查仍可用。
- 发现更新在标题栏右侧、最小化按钮左边显示蓝底白字徽章，文字前带白色下载图标，不绘制截图红框。浅深主题及 900px 宽度均适配。
- 点击徽章直接保存、下载、校验和安装，显示进度；下载前和启动安装前分别保存，失败不继续安装。后台检测不自动安装、不弹窗打断写作。
- 检查并发合并，替换/卸载释放更新资源；安装期间保护现有资源，防止未完成的后台检测释放正在使用的更新。

## 本地验证
- 47 项单元测试通过，包括定时检测、忙碌延迟、失败静默、停用定时器、并发检查、资源保护、旧数据默认开关、更新保存顺序、保存/下载失败阻止安装，以及既有数据/文件兼容测试。
- 5 项 Rust/SQLite 测试通过。
- 17 条浏览器端到端流程通过；白色下载图标加入后，4 条 rc2 专项流程再次通过。
- 专项覆盖删除/移动取消与确认、永久删除取消、空知识库删除确认、自动检测徽章颜色与位置、单击进入安装进度、关闭自动检测后重开保留、手动检查，以及旧版写作回归。
- 自动检测发现未来版本及点击安装的浏览器测试使用模拟更新 API与虚拟时间，不据此声称已从 rc2 实际安装尚未发布的下一版本。安装器及真实 GitHub 签名升级使用隔离 Windows CI 另行验证。
- 浏览器使用独立 IndexedDB，原生和 CI 使用一次性测试数据，不读取或覆盖用户正式知识库。
